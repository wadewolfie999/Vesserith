# 0.2.1 — ultra-minimal copy

Status: implementation requested on 2026-09-10.
Baseline: tagged `v0.2.0` at `3218ad9`. Branch: `codex/0.2.1-copy-slim`.

## Problem

The orientation surface repeated explanatory prose and status language. It made
the app slower to scan than an orientation instrument should be.

## Authorized scope

- Reduce product-owned rendered interface copy by at least 55 percent.
- Keep the opening objective, focus, and chosen action visible.
- Retain short labels for state, next action, uncertainty, and stopping point.
- Keep the full changelog in What changed.

## Exclusions

No saved-orientation edits, API, SQLite, schema, migration, or recovery changes.

## Acceptance checks

- Static copy is reduced by at least 55 percent, excluding saved values and the
  complete changelog.
- The opening view exposes objective, focus, and the chosen action.
- Maps, inspectors, editor, History, What changed, save, and export remain usable.
- Existing tests, lint, build, and browser checks pass.

## Recovery implications

This is a schema-1 frontend and copy change. Revert code to `v0.2.0` if needed;
the local orientation database remains compatible.

## Verification results — 2026-09-10

- Rendered static copy inventory: 138 words at `v0.2.0`, 37 words now (73.2
  percent reduction). Saved orientation values and the full changelog were
  excluded from both counts.
- All 16 backend persistence, recovery, and local-security tests passed.
- Frontend lint, TypeScript production build, dependency check, and whitespace
  validation passed.
- Browser verification confirmed the concise opening view, both maps, signal
  inspector, History, What changed, and enabled export on clean saved state.
- No saved orientation was edited or saved during verification.
